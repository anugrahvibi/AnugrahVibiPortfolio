# Anugrah Vibi — Portfolio

A minimal, text-first developer portfolio inspired by the structure of [Aryan Baburajan's portfolio](https://www.aryanbaburajan.com/).

## Run locally

Open `index.html` in a browser. The page uses plain HTML and CSS, so no build step or package installation is required.

## Structure

- Intro and profile links
- What I'm working on
- Highlights
- Side Quests
- Contact
